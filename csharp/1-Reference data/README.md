**Ganymede's Reference Data, also referred to as Static Data,** serves as a comprehensive repository housing essential definitions for various asset types and structures, including Equities, ETFs, Futures, Options, Cryptos, Bonds, Indices and more. Our meticulously crafted model is designed to efficiently manage financial instruments, offering a well-structured framework for standardizing and normalizing asset class definitions.

Think of the Reference Data as a centralized database meticulously organizing assets and facilitating seamless navigation. 

It goes beyond simple categorization, enabling intricate linkages between assets. For instance, it efficiently connects components within an Index and associates related options with each individual equity. This meticulous organization streamlines data retrieval and analysis, empowering users to make informed decisions with ease and accuracy.

For further details and documentation, visit [here](https://ganymede.cloud/docs/#systemathics/apis/services/static_data/v1/static_data).
